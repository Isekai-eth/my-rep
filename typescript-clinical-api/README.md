# TypeScript Clinical API

A small, strongly typed Node.js/TypeScript example for clinical arithmetic.

## Included

- BMI calculation
- BMI category mapping
- Weight-based dose arithmetic
- Runtime input validation
- Node's built-in test runner
- Strict TypeScript compilation

## Run

```bash
npm install
npm run build
npm test
```

This project is an educational software example. It does not provide medical advice or replace prescribing information, clinical guidelines, or local protocols.
