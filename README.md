# Clinical Utility Toolkit

A small, testable Python toolkit for common clinical calculations and documentation helpers.

## Features
- Weight-based medication dose calculation
- Body-mass index (BMI)
- Estimated creatinine clearance using Cockcroft–Gault
- Simple unit-safe validation
- Automated tests with pytest
- GitHub Actions CI

> This project is educational software. It does not replace clinical judgment, local protocols, prescribing information, or specialist advice.

## Development

```bash
python -m pip install -e ".[dev]"
pytest
```
